# 평가와 해석 범위

원본 `RAG_Chatbot.ipynb`의 저장 출력과 코드에 근거합니다(2026-09-13 확인).

## 평가 정의

`evaluate_retriever`는 각 질문에서 기대 키워드가 처음 포함되는 검색 청크의 순위를 구합니다. Hit@k는 k개 안에 키워드가 있는 비율, MRR은 최초 순위 역수의 평균입니다. 정확한 근거 문서의 사람 평가나 답변 사실성의 전면 검증과는 다릅니다.

## 표본 수와 기록

- 튜닝 18문항. 100/180/300자 Hit@3: 0.778/0.889/0.944, MRR: 0.630/0.796/0.806.
- 180자 설정에서 top-k 1/2/3/5/7의 Hit@k: 0.722/0.833/0.889/1.000/1.000.
- 최종 180자/top-k 5: Hit@5 1.000, MRR 0.821.
- 도메인 내 최고 유사도 최소 0.607·평균 0.703, 외 최대 0.461·평균 0.302. 선택 임계값 0.53은 평균끼리의 단순 중간값이 아니며, 관측된 외 최대와 내 최소 사이에 있습니다.
- 별도 holdout 6문항(정보 답변 4, 자료 미사용 응대 2): 저장 출력 6/6. 이 작은 표본으로 일반화를 입증했다고 표현하지 않습니다.
- 멀티턴 비교 2문항: 미용실 관련 문서가 검색되도록 바뀐 사례가 저장돼 있습니다. 종합적인 멀티턴 벤치마크는 아닙니다.

## 알려진 제약

- 180자 설정 8,945개 청크 중 106개가 128토큰 초과. 입력 잘림을 완전히 제거한 것은 아닙니다.
- 자료가 없는 사업 질문은 유사 문서가 임계값을 넘어 프롬프트 방어에 의존할 수 있습니다.
- 키 없는 모드의 결과는 LLM 생성 성능과 구분해야 합니다.
- 테스트 출력은 기존 실행 기록입니다. 현재 환경에서 모델 다운로드·LLM 호출을 포함한 전면 재현은 수행하지 않았습니다.
- 노트북 설명 일부에는 15문항으로 적혀 있으나 실제 평가 리스트와 출력은 18문항입니다. 과거 기록의 차이를 보존하여 밝힙니다.
