# 자료 출처와 정리 이력

## 원본

작성자가 제공한 데이터사이언스세미나/기말고사 폴더의 노트북, 검색 전용 데모, JSONL, CSV를 사용했습니다. 발표 PDF 13페이지와 기존 저장 출력을 함께 확인했습니다. 원본 폴더는 수정하지 않았습니다.

## 공유본 변경

- 노트북 실행 출력과 셀 메타데이터 제거; 실험 출력은 `recorded-results.json`으로 별도 발췌.
- 템플릿 제목·편집 주석 정리, 키 직접 입력 안내 제거.
- 존재하지 않는 독립 변환 스크립트 안내를 노트북 셀 참조로 정정.
- 검색 데모의 개인 절대 경로를 저장소 기준 경로로 변경, 캐시를 `.cache`로 이동.
- 실제 LLM 호출이 없는 검색 데모의 모드 표시 정정. 알고리즘은 그대로 유지.
- 원본 데이터 파일은 내용 변경 없이 복사.

## 본인 진술로 확인한 사실

4인 팀, 2026.03–06, 팀장 및 코딩 전반 담당. 팀원은 내용 정리·PPT·발표 담당. 멀티턴·배포 제안과 마감에 대한 반대, 짧은 구현 가능성 설명으로 설득. 실패 시 기본 기능으로 돌아갈 수 있다는 판단. Netlify 배포 및 발표 참가자의 개별 컴퓨터 접속.

## 확보되지 않은 자료

Netlify 사이트 URL·배포 설정·프런트엔드 원본·당시 백엔드 연결 방식·의존성 잠금 파일·정확한 과목 성적 및 교수 평가. 추정으로 채우지 않았습니다. 초기 데이터 구축 설명의 ‘조원 크롤링’ 표현은 개별 작업 분담을 증명하지 않으므로, 개인 기여는 최신 본인 설명을 기준으로 기록했습니다.

원본 PDF·영상·압축파일은 개인 및 팀 발표 자료로 남겨두고 이 공개 저장소에는 포함하지 않았습니다. 저장소 정리 중 추가한 문서·검사는 당시 프로젝트 산출물과 구분합니다.
